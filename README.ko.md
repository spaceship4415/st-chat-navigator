# 채팅 내비게이터 사용 가이드

[English](README.md)

긴 채팅에서 원하는 메시지를 찾아가고 정리하는 확장입니다.
마법봉 메뉴 하나에서 **채팅 검색, 번호로 이동, 책갈피, 범위 숨기기·삭제, 맨 위/아래**를 쓸 수 있어요.
버튼은 모두 휴대폰에서 누르기 좋은 크기로 만들었습니다.

---

## 1. 설치하기

1. 실리태번 위쪽의 **확장 프로그램**(퍼즐 모양 아이콘)을 누릅니다.
2. **Install Extension**을 누릅니다.
3. 이 저장소 주소를 붙여 넣고 **Install**을 누릅니다.

설치가 끝나면 입력창 왼쪽 **마법봉 메뉴**에 **채팅 내비게이터**가 생깁니다.

---

## 2. 메뉴판

마법봉 → **채팅 내비게이터**를 누르면 큰 버튼이 모인 메뉴판이 뜹니다.
맨 위에는 지금 채팅의 메시지 수(예: `메시지 120개 (#0 ~ #119)`)가 나옵니다.

| 버튼 | 하는 일 |
| --- | --- |
| 채팅 검색 | 지금 열린 채팅에서 찾고, 누르면 그 메시지로 이동 |
| 번호로 이동 | 메시지 번호를 넣으면 이동 (`12`, `#12` 둘 다 됨) |
| 책갈피 (N) | 책갈피 목록. 누르면 이동, ✎로 메모, ✕로 빼기 |
| 이 채팅 정보 | 요약, 페르소나, 작가 노트, 채팅 덮어쓰기, 로어북을 한 화면에서 보고 바꾸기 |
| 범위 숨기기·보이기 | `#시작 ~ #끝` 메시지를 AI에게 안 보내기 / 다시 보내기 |
| 범위 삭제 | `#시작 ~ #끝` 메시지 삭제 (되돌릴 수 없음) |
| 골라서 숨기기·삭제 | 메시지를 탭해서 골라 한꺼번에 숨기기·보이기·삭제 |
| 맨 위로 / 맨 아래로 | 채팅의 처음이나 끝으로 |

메시지 번호는 실리태번이 메시지마다 보여 주는 `#번호` 그대로입니다. 0부터 시작해요.

---

## 3. 채팅 검색

- 띄어쓰기로 여러 단어를 넣으면 **모두 들어 있는** 메시지만 나옵니다. 대소문자는 가리지 않아요.
- 최근 메시지부터 100개씩 보여 주고, 더 있으면 아래 **더 보기**를 누릅니다.
- 결과마다 `#번호`, 보낸 사람, 찾은 단어가 표시된 앞뒤 문장이 나옵니다.
- 목록을 내려도 검색창은 위에 그대로 있어서 바로 고쳐 쓸 수 있어요.

> 아주 오래된 메시지로 가면 그 사이 메시지를 전부 화면에 불러와야 합니다.
> 300개가 넘으면 휴대폰이 잠깐 멈출 수 있어서, **먼저 물어봅니다.** 취소하면 검색 결과는 그대로 남아요.

---

## 4. 책갈피

1. 메시지 오른쪽 위 `⋯`를 누릅니다.
2. ☆를 누르면 책갈피가 되고, 이름 옆에 **★**가 붙습니다.
3. 다시 누르면 빠집니다.

메뉴판의 **책갈피**에서 목록을 보고, 누르면 그 메시지로 갑니다.

책갈피는 번호가 아니라 **메시지 자체에** 저장돼서, 앞쪽 메시지를 지워 번호가 바뀌어도 따라갑니다.

책갈피 목록에서 ✎를 누르면 **메모**를 달 수 있습니다(40자까지). `1장: 첫 만남`처럼 장면 이름을 달아 두면 목록이 목차처럼 되고,
채팅에서도 이름 옆에 `★ 1장: 첫 만남`으로 보입니다. 비우고 저장하면 메모가 지워집니다.

### 실리태번의 브랜치·체크포인트와 다른 점

| | 책갈피 (이 확장) | 브랜치 (실리태번) | 체크포인트 (실리태번) |
| --- | --- | --- | --- |
| 하는 일 | 지금 채팅 안의 메시지에 **표시만** | 그 메시지까지 **새 채팅으로 복사** | 그 메시지까지 **새 채팅으로 복사** |
| 만든 뒤 | 그대로 | **새 채팅으로 바로 이동** | **지금 채팅에 그대로**, 메시지에 깃발이 생김 |
| 다시 가기 | 책갈피 목록에서 누르면 그 메시지로 스크롤 | 채팅 목록에서 `… - Branch #1` 열기 | 깃발을 누르면 그 채팅이 열림 |
| 쓸 때 | 다시 찾아볼 장면 표시, 목차 | 여기서 다른 전개를 바로 써 보기 | 이 시점을 저장해 두고 원래 대화 계속하기 |

책갈피는 새 파일을 만들지 않고, 브랜치·체크포인트로 만든 채팅은 원래 채팅과 따로 이어집니다.

---

## 5. 이 채팅 정보

메뉴판의 **이 채팅 정보**는 **지금 열린 채팅**에 걸려 있는 것을 한 화면에 모아 보여 줍니다.
실리태번에서는 여러 메뉴에 흩어져 있는 것들이에요.

- **요약**: 채팅 파일 이름, 메시지 수(숨긴 메시지 수), 대략적인 토큰 수(숨긴 메시지 제외), 첫 메시지와 마지막 메시지 날짜.
- **페르소나**: 지금 쓰는 페르소나가 나오고, 목록에서 고르면 바로 바뀝니다.
  **이 채팅에 고정**을 켜면 이 채팅을 열 때마다 그 페르소나로 바뀝니다(실리태번의 페르소나 '채팅에 고정'과 같음).
  고정된 상태에서 다른 페르소나를 고르면 고정도 새 페르소나로 옮겨 갑니다.
- **작가 노트**: 이 채팅의 작가 노트(Author's Note) 내용, 위치(시나리오 앞·뒤, 채팅 안의 깊이와 역할), 간격을 바로 고칩니다.
  간격이 3이면 메시지 3개마다 넣고, 0이면 넣지 않습니다. 실리태번의 작가 노트 패널과 같은 값이에요.
- **채팅 덮어쓰기**: 이 채팅에서만 캐릭터 카드 대신 쓰는 시나리오, 예시 대화, 시스템 프롬프트가 있는지 보여 줍니다.
  모르고 켜 둔 채 지내기 쉬워서 앞부분을 미리 보여 주고, **편집**을 누르면 실리태번의 덮어쓰기 창이 열립니다.
- **로어북**: 채팅 로어북(이 채팅에서만 추가로 적용, 실리태번 채팅 메뉴의 '채팅 로어북'과 같음)을 바꾸거나 **(없음)**으로 풉니다.
  옆의 ✎는 연결된 로어북을 편집기에서 열고, ＋는 새 로어북을 만들어 이 채팅에 연결한 뒤 바로 편집기를 엽니다(이름은 채팅 이름이 기본값이고, 이미 있는 이름이면 덮어쓰지 않고 멈춥니다).
  그 아래에는 **지금 적용되는 로어북 전체**가 채팅 / 캐릭터(그룹이면 멤버마다) / 페르소나 / 전역으로 나뉘어 나옵니다.
  파일이 없어진 로어북은 줄이 그어져 보입니다. 캐릭터·페르소나·전역 로어북은 보기만 하고 바꾸지는 않습니다.

작가 노트와 채팅 덮어쓰기는 자주 쓰지 않아서 **접혀 있고**, 제목 옆 불빛으로 상태만 알려 줍니다.
초록 불은 사용 중, 노란 불은 작가 노트에 내용은 있지만 간격이 0이라 안 들어가는 상태, 회색은 비어 있음이에요. 제목을 누르면 펼쳐집니다.

### 작가 노트와 채팅 덮어쓰기가 뭔가요?

둘 다 **AI에게 몰래 건네는 쪽지** 같은 기능인데, 성격이 조금 다릅니다.

#### 작가 노트 (Author's Note)

**이 채팅에서 AI에게 계속 상기시키고 싶은 말**을 적는 칸입니다. 화면에는 안 보이고, AI에게 보내는 프롬프트에만 슬쩍 끼워 넣어져요.

- 지금 상황을 잊지 않게: `[현재 장소: 비 오는 밤의 기차역. 두 사람은 방금 싸운 상태]`
- 문체나 분위기를 잡을 때: `[짧고 건조한 문장으로. 감정 묘사는 절제할 것]`
- 이야기가 길어져서 AI가 설정을 자꾸 까먹을 때

캐릭터 카드를 고치지 않고 **이 채팅에서만** 적용된다는 게 핵심이에요. 장면이 바뀌면 내용만 바꿔 주면 됩니다.

| 설정 | 뜻 |
| --- | --- |
| 위치: 시나리오 앞·뒤 | 프롬프트 윗부분, 캐릭터 설정 근처에 넣습니다. 배경 설정 느낌 |
| 위치: 채팅 안 + 깊이 | 대화 사이에 끼워 넣습니다. 깊이 4면 최근 메시지 4개 위에 들어가요. **최근 대화에 가까울수록 AI가 더 강하게 따릅니다** |
| 역할 | 그 쪽지를 누가 한 말처럼 넣을지(시스템 / 사용자 / AI). 보통 시스템이면 됩니다 |
| 간격 | 1이면 매번, 3이면 메시지 3개마다 한 번, 0이면 넣지 않음 |

보통은 **채팅 안, 깊이 2~4, 간격 1**이 무난합니다.

#### 채팅 덮어쓰기 (Chat Overrides)

캐릭터 카드에 적힌 내용을 **이 채팅에서만 다른 내용으로 바꿔치기**하는 기능입니다. 카드 원본은 그대로 남아요.

| 항목 | 예시 |
| --- | --- |
| 시나리오 | 카드에는 "학교에서 처음 만남"인데, 이 채팅은 "10년 뒤 재회" 세계관으로 하고 싶을 때 |
| 예시 대화 | 카드의 말투 예시 대신 이 채팅에서만 다른 말투를 보여 주고 싶을 때 |
| 시스템 프롬프트 | 이 채팅에서만 AI에게 주는 기본 지시문을 바꾸고 싶을 때 |

**한 캐릭터로 여러 평행세계 채팅을 돌릴 때** 유용합니다. 카드를 복사하지 않고 채팅마다 시나리오만 바꾸면 되니까요.

#### 둘의 차이

- **작가 노트** = 원래 내용에 **덧붙이는** 쪽지. 자주 바뀌는 "지금 상황"용.
- **덮어쓰기** = 카드 내용을 **바꿔치기**. 잘 안 바뀌는 "이 채팅의 세계관"용.

둘 다 **모르고 켜 둔 채 잊어버리기 쉬워서** 불빛을 달아 두었습니다.
"AI가 왜 자꾸 이상한 설정을 말하지?" 싶을 때 이 창에서 불이 켜져 있는지 보면 원인을 빨리 찾을 수 있어요.

---

## 6. 범위 숨기기·보이기

숨긴 메시지는 **화면에는 남고 AI에게만 안 보냅니다.** 채팅이 길어져 토큰을 줄이고 싶을 때 씁니다.

- 처음 열면 **최근 20개를 남기는 범위**가 미리 채워져 있습니다. 메시지가 20개 이하면 끝 칸이 비어 있어요.
- 번호를 넣으면 `메시지 30개 · 지금 숨김 0개`처럼 미리 알려 줍니다.
- **[숨기기]**로 숨기고, 같은 범위에서 **[보이기]**를 누르면 다시 보냅니다.
- 시작과 끝을 거꾸로 넣어도 알아서 맞춥니다.

숨긴 메시지는 이름 옆에 **"숨김"** 배지가 붙습니다.

---

## 7. 범위 삭제

**지운 메시지는 되돌릴 수 없습니다.** 그래서 두 번 확인합니다.

1. 범위를 넣으면 `메시지 5개 삭제 · 책갈피 1개 포함`처럼 미리 보여 줍니다. (처음엔 비어 있어요.)
2. **[다음]**을 누르면 한 번 더 묻습니다. 채팅 전체를 골랐거나 개수가 많으면 그것도 알려 줍니다.
3. **[삭제]**를 눌러야 지워집니다.

> 메시지 하나만 지울 때는 메시지 `⋯` 메뉴 맨 끝의 🗑 버튼이 빠릅니다. 편집 모드에 들어가지 않아도 되고, 똑같이 확인을 거칩니다.
>
> **책갈피한 메시지가 섞여 있으면** 그 전에 어떤 메시지인지 목록으로 보여 주고 묻습니다.
> **[책갈피 빼고 삭제]**(기본)를 누르면 책갈피한 메시지는 남기고 나머지만 지우고, **[모두 삭제]**를 누르면 함께 지웁니다.
> 골라서 삭제할 때도 똑같이 묻습니다.

AI에게만 안 보내고 싶은 거라면 삭제 대신 **범위 숨기기**를 쓰세요.
수백 개를 지우면 하나씩 지워서 휴대폰에서는 몇 초 걸릴 수 있습니다.

---

## 8. 골라서 숨기기·삭제

번호로 넣기 번거로울 때, 화면에서 **메시지를 직접 탭해서** 고릅니다.

1. 메뉴판에서 **골라서 숨기기·삭제**를 누르면 입력창 자리에 선택 막대가 뜹니다.
2. 메시지를 탭하면 오른쪽 위에 ✓가 생기고, 다시 탭하면 빠집니다.
3. 여러 개를 이어서 고를 때는 **[범위]**를 켜고 **첫 메시지와 마지막 메시지**를 탭하세요. 그 사이가 모두 선택됩니다.
4. **[숨기기] [보이기] [삭제]** 중 하나를 누릅니다. 삭제는 한 번 더 묻습니다.
5. 끝나면 **[완료]**.

- `#3, #4, #5, #9`처럼 떨어져 있어도 한 번에 처리됩니다.
- 선택 모드에서는 메시지를 탭해도 편집·스와이프·링크가 동작하지 않고 고르기만 합니다.
- 답변 생성이 시작되거나 다른 채팅으로 가면 선택 모드는 저절로 끝납니다.
- 오래된 메시지는 위로 스크롤해서 불러온 뒤 고르면 됩니다.

---

## 9. 설정

확장 프로그램 → **Chat Navigator**에서 켭니다.

| 설정 | 하는 일 |
| --- | --- |
| 읽던 위치 이어 보기 | 채팅에 다시 들어오면 **"📖 읽던 곳 #120 이어 보기"** 칩이 떠서, 누르면 그 자리로 갑니다 |
| 스크롤할 때 현재 위치 표시 | 스크롤하는 동안 위쪽에 `#120 / #450`이 잠깐 보입니다 |
| 답변이 오면 처음 부분에서 멈추기 | 긴 답변이 오면 맨 아래까지 따라 내려가지 않고 답변 첫 줄에서 멈춥니다 |
| 맨 아래로 버튼 띄우기 | 채팅 아래 가운데에 ⇊ 버튼을 띄웁니다. 이미 맨 아래면 숨습니다 |
| 맨 위로 버튼 띄우기 | 그 옆에 ⇈ 버튼을 띄웁니다. 이미 맨 위면 숨습니다 |
| 턴 알림 [N] 턴마다 | AI 답변이 N개, 2N개, … 가 될 때마다 알림 |
| 토큰 알림 [N] 토큰마다 | 채팅 전체가 N 토큰, 2N 토큰, … 을 넘을 때마다 알림 |

- **읽던 위치**는 이 기기 브라우저에만 저장됩니다. 폰과 PC가 각자 읽던 곳을 따로 기억해요. 맨 아래까지 읽고 나가면 기억하지 않고, 칩은 15초 뒤 저절로 사라집니다.
- **처음 부분에서 멈추기**: 스트리밍이면 답변이 화면보다 길어지는 순간 첫 줄을 화면 맨 위에 붙잡고, 한 번에 오는 답변이면 다 온 뒤 첫 줄로 올립니다. 한 화면에 다 들어오는 짧은 답변과 이어쓰기(continue)는 건드리지 않고, 읽다가 직접 내린 건 다시 끌어올리지 않습니다.
  - 실리태번 사용자 설정의 **채팅 자동 스크롤**과는 다릅니다. 그걸 끄면 답변뿐 아니라 내 메시지를 보낼 때나 채팅을 열 때도 맨 아래로 가지 않습니다. 이 옵션은 **답변을 읽을 때만** 첫 줄에서 멈추니, 실리태번 쪽은 켜 두고 이 옵션을 켜는 걸 추천합니다. (실리태번 쪽을 끄면 따라 내려가는 일 자체가 없어서 이 옵션은 할 일이 없습니다.)
  - 맨 위/아래 버튼, 번호로 이동, 검색 결과 이동은 실리태번의 채팅 자동 스크롤 설정과 상관없이 동작합니다.
- 떠 있는 버튼은 둘 다 기본으로 꺼져 있고, 하나만 켜도 됩니다. 메시지 버튼이나 스와이프 화살표를 가리지 않게 가운데에 둡니다.
- 토큰은 지금 쓰는 토크나이저로 세고, 숨긴 메시지는 뺍니다.
- 같은 구간에서는 한 번만 알리고, 채팅마다 기억해서 새로고침해도 다시 뜨지 않아요.
- 알림을 켜거나 N을 바꾸면 **지금부터** 셉니다. 켜자마자 알림이 뜨지는 않아요.
